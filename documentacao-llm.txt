1. VISÃO GERAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Plataforma SaaS jurídica com inteligência artificial avançada, desenvolvida
para escritórios de advocacia e profissionais do Direito. Combina geração
de documentos por IA, pesquisa jurisprudencial unificada, rede neural
auto-evolutiva, visão neural com reconhecimento facial, CRM de clientes,
gestão processual, assinatura digital, pagamentos integrados, voz humana
(ElevenLabs TTS) e colaboração em tempo real.

Stack tecnológico:
  • Frontend: React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui
  • Backend: Supabase (PostgreSQL + Auth + Storage + Edge Functions + Realtime)
  • IA Multi-provider: OpenAI, Gemini, DeepSeek, Perplexity, Groq, Mistral, Anthropic
  • Visão Neural: Gemini Vision + Groq Vision + Mistral Vision (multi-provider)
  • TTS (Text-to-Speech): ElevenLabs API (voz humana profissional masculina)
  • Reconhecimento Facial: FaceDetector API + Gemini Vision (anti-spoofing)
  • Pagamentos: Stripe (Checkout, Connect, Webhooks, Faturas)
  • Assinatura Digital: ClickSign (webhooks, status realtime)
  • Integrações Google: Drive, Docs, Sheets, Gmail, Calendar, Contacts
  • Editor de Texto: TipTap (rich text, colaboração, extensões)
  • Visualização: Recharts, React Flow (@xyflow/react), Three.js
  • Colaboração: Yjs + y-webrtc + y-indexeddb
  • i18n: Suporte multilíngue (PT-BR, EN, ES)
  • IoT / MQTT: HiveMQ Cloud (WebSocket TLS porta 8884)
  • Bluetooth BLE: Web Bluetooth API (GATT services)
  • Mobile PWA: vite-plugin-pwa (instalável, offline, sensores web)
  • Mobile Nativo: Capacitor (iOS/Android com acesso completo a sensores)
  • Sensores Nativos: Câmera, GPS, Acelerômetro, Háptica, Bateria, Rede
  • Assistente de Voz: Orion (Web Speech API + comandos IoT/BLE/sensores)
  • Raciocínio Neural: Motor de intenção v3 (emocional + contextual + continuidade)
  • Neurolinguística: Limpeza de markdown/código para TTS, entonação com ; e quebra de cláusulas
  • Documentos Internacionais: 15+ tipos (LOI, MOU, NDA, JV) com templates bilíngues EN/PT
  • AML Screening: Triagem anti-lavagem com múltiplas listas e jurisdições internacionais

J.1 WEB BLUETOOTH MANAGER
─────────────────────────
  Arquivo: src/lib/neural/bluetooth-manager.ts
  
  Classe BluetoothDeviceManager que encapsula a Web Bluetooth API:
  • requestDevice() — Scan de dispositivos BLE com filtros por serviço
  • connect() — Pareamento e conexão GATT
  • readCharacteristic() / writeCharacteristic() — Leitura/escrita de dados
  • startNotifications() — Notificações de características em tempo real
  • Reconexão automática em caso de desconexão
  
  Serviços GATT suportados:
  • Battery Service (0x180F) — Nível de bateria
  • Heart Rate (0x180D) — Frequência cardíaca
  • Device Information (0x180A) — Informações do dispositivo
  • Custom Services — Serviços BLE customizados
  
  Limitações:
  • Requer Chrome/Edge (Firefox/Safari não suportam Web Bluetooth)
  • Requer HTTPS (ou localhost)

  Pipeline de limpeza (Regex):
  1. Remove blocos de código (``` ... ```)
  2. Remove markdown bold/italic (**texto**, *texto*)
  3. Remove headers (## texto, ### texto)
  4. Remove comentários de código (// texto, /* texto */)
  5. Remove URLs (http:// e https://)
  6. Remove tags HTML (<tag>)
  7. Remove tabelas markdown (|---|---|)
  8. Remove emojis técnicos (🔧, ⚙️, 📊, etc.)
  9. Remove caracteres decorativos (━, ─, ═)
  10. Limpa espaços duplicados
  
  Entonação:
  • Ponto e vírgula (;) reconhecido como fim de sentença
  • Cláusulas >120 caracteres quebradas automaticamente em vírgulas
  • Pausas naturais inseridas para pacing humano
