## What I do

- Wake word detection ("Orion", "Painel")
- Natural language intent classification
- Command execution across all features
- Voice identity recognition (creator detection)

## When to use me

Use this skill for:
- Navigation: "Orion, abrir documentos"
- Media: "Orion, tocar música X"
- Vision: "Orion, ativar visão"
- Video: "Orion, aumentar a tela"
- Evolution: "Orion, auto evoluir"

## Supported Commands

### Navigation
- "abrir [seção]" - Navigate to any section
- "ir para [destino]" - Go to destination

### Media
- "tocar [música/video]" - Play media
- "pausar/continuar" - Pause/Resume
- "próxima/anterior" - Next/Previous track

### Vision
- "ativar/desativar visão" - Toggle camera
- "o que você vê?" - Describe scene

### Video Control
- "aumentar/diminuir a tela" - Fullscreen
- "minimizar vídeo" - Minimize player

### System Evolution (Creator Only)
- "auto evoluir" - Self-programming
- "otimizar" - Performance optimization
