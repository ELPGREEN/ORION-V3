## What I do

- Build projects (npm run build)
- Run tests with coverage
- Execute linters and formatters
- Type checking with TypeScript
- Deploy to production
- Deploy Supabase Edge Functions

## When to use me

- "Orion, build" - Build the project
- "Orion, run tests" - Execute test suite
- "Orion, lint" - Fix code style issues
- "Orion, typecheck" - Verify TypeScript types
- "Orion, deploy" - Deploy to production

## Commands

- build, test, lint, typecheck, deploy, deploy-edge
