## What I do

- Switch between 15+ LLM providers
- Use free tier models from each provider
- Support for local models (Ollama, LM Studio, llama.cpp)

## Supported Providers

### Cloud (Free Tier)
- OpenAI: gpt-4o-mini, gpt-4o
- Anthropic: claude-3-haiku, claude-3.5-sonnet
- Google: gemini-1.5-flash, gemini-2.0-flash
- DeepSeek: deepseek-chat, deepseek-coder
- Groq: llama-3.1-70b, mixtral-8x7b
- Cohere: command-r-plus, command-r
- Mistral: mistral-large, codestral
- HuggingFace: Llama-3.1-70B, Qwen2.5-Coder

### Local (Free)
- Ollama: llama3, codellama, mistral
- LM Studio: llama3, codellama
- llama.cpp: llama-3-70b

## When to use me

Use this skill when you want to:
- "Orion, usar deepseek" - Switch to DeepSeek
- "Orion, usar ollama" - Use local Ollama
- "Orion, qual modelo?" - Check current model
- "Orion, listar modelos" - Show available models

## Provider Selection

Simply say the provider name to switch:
- "Orion, usar anthropic"
- "Orion, usar google"
- "Orion, usar openrouter"
