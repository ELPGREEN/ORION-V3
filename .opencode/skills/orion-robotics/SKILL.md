## What I do

- Connect to ROSBridge WebSocket servers
- Send velocity commands (cmd_vel)
- Navigate with Nav2 goals
- Monitor robot state (odometry, IMU, battery)
- Emergency stop functionality

## When to use me

Use this skill when working with:
- ROS2-based robots
- AGV/AMR vehicles
- Industrial automation
-ROS2 simulation

## Features

- Joystick control for teleoperation
- Navigation goal setting
- Real-time telemetry monitoring
- Multiple robot fleet management
- Digital twin visualization
- VDA5050 protocol support
