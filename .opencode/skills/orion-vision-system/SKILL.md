## What I do

- Real-time camera feed analysis
- Object detection using MediaPipe + YOLOv8
- Face detection and recognition
- Hand gesture tracking
- Text OCR (Optical Character Recognition)
- Motion detection with optical flow

## When to use me

Use this skill when you want to:
- "Orion, ativar visão" - Activate camera
- "Orion, desativar visão" - Deactivate camera
- "Orion, o que você vê?" - Describe scene
- "Orion, identificar objetos" - List detected objects
- "Orion, ler texto" - OCR text detection

## Features

- 100% local processing (no data leaves device)
- Adjustable detection modules (faces, hands, objects, text, motion)
- Confidence threshold control
- Real-time FPS monitoring
